# Planhat CRM — Data Model & Schema Definition

[Planhat](https://www.planhat.com/) is a Customer Success / customer platform (CRM). Its
API is a JSON REST API (base URL `https://api.planhat.com`, Bearer-token auth; usage
events go to `https://analytics.planhat.com`). This document defines the objects
(models) Planhat stores, their fields, and the data types used.

> Compiled from Planhat's developer documentation (docs.planhat.com /
> planhat.com/developers) and open-source Planhat API clients. Field lists cover the
> standard documented fields; every tenant can extend any model with custom fields
> (see [Custom fields](#custom-fields)), so exact schemas vary per tenant.

## Type conventions

| Type | Meaning |
|---|---|
| `ObjectId` | 24-char hex MongoDB-style id string, e.g. `"560d5b8bf837f2b845b8b93c"` |
| `string` | UTF-8 string |
| `number` | JSON number (integer or float; money is a plain number in the license currency) |
| `boolean` | `true` / `false` |
| `date` | ISO 8601 timestamp string, e.g. `"2026-08-13T00:00:00.000Z"` (day-granularity fields still use this format) |
| `string[]`, `ObjectId[]` | JSON arrays |
| `object` | Nested JSON object |

## Core concepts

- **Three ways to identify a record.** Almost every model carries:
  - `_id` (`ObjectId`) — Planhat's native id, generated on creation.
  - `externalId` (`string`) — your own id for the record (your database's key).
  - `sourceId` (`string`) — the id in an integrated source system (e.g. Salesforce or
    HubSpot record id).

  API routes accept any of the three: `/companies/{_id}`,
  `/companies/extid-{externalId}`, `/companies/srcid-{sourceId}`.
- **Company-centric model.** Nearly everything hangs off a Company via a `companyId`
  (`ObjectId`) reference; many child objects also expose a read-only `companyName`.
- **Timestamps.** Models carry `createdAt` and `updatedAt` (`date`), maintained by
  Planhat.
- **Custom data.** Every model has a `custom` (`object`) property holding
  tenant-defined fields keyed by field name.
- **Upserts.** Bulk endpoints upsert on `_id` / `externalId` / `sourceId`, so the same
  schema is used for create and update.

## Entity relationships

```
User (team member)
  └─ owns ──► Company ◄── parent/child ──► Company
                │
                ├── End User        (people at the customer)
                ├── License         (recurring revenue / subscriptions)
                ├── Sale            (non-recurring revenue)
                ├── Invoice         (billing documents)
                ├── Churn           (churn / downgrade log)
                ├── Opportunity     (expansion / renewal deals)
                ├── Asset           (things you track per customer)
                ├── Project         (time-bounded engagements)
                ├── Objective       (success goals + health)
                ├── Campaign        (in-account campaigns)
                ├── Workspace       (sub-instances / departments)
                ├── Task            (to-dos, calls, meetings)
                ├── Conversation    (emails, notes, calls, chats, tickets)
                ├── NPS             (survey responses, per End User)
                └── Metrics         (time-series: usage events & dimension data)

Issue (bug / feature request) ──► many Companies / many End Users
Custom Field (metadata) ──► defines extra fields on any model above
```

## Company (`/companies`)

The account object — your customer (or prospect). The anchor of the whole model.

| Field | Type | Description |
|---|---|---|
| `_id` | `ObjectId` | Planhat id |
| `name` | `string` | **Required.** Company name |
| `slug` | `string` | URL-safe name, generated by Planhat |
| `externalId` | `string` | Your id for the company |
| `sourceId` | `string` | Id in an integrated CRM (Salesforce, HubSpot, …) |
| `owner` | `ObjectId → User` | Account owner (e.g. CSM) |
| `coOwner` | `ObjectId → User` | Secondary owner |
| `status` | `string` enum | Lifecycle status: `prospect`, `coming`, `customer`, `canceled`, `lost` |
| `phase` | `string` | Current lifecycle phase (tenant-defined list, e.g. `onboarding`, `adoption`, `renewal`) |
| `phaseSince` | `date` | When the current phase was entered |
| `domains` | `string[]` | Email/web domains used to auto-match end users and activity to this company |
| `web` | `string` | Website URL |
| `address`, `city`, `zip`, `country` | `string` | Postal address parts |
| `phonePrimary` | `string` | Main phone number |
| `description` | `string` | Free-text description |
| `h` | `number` | Health score (0–10), calculated by Planhat |
| `csmScore` | `number` | Manual CSM pulse score, 1–5 |
| `mrr` | `number` | Monthly recurring revenue, calculated from licenses |
| `arr` | `number` | Annual recurring revenue, calculated (`mrr × 12`) |
| `mrrTotal` | `number` | MRR including child companies |
| `nrr30` | `number` | Non-recurring revenue, rolling last 30 days |
| `nrrTotal` | `number` | Total non-recurring revenue |
| `customerFrom` | `date` | Became a customer |
| `customerTo` | `date` | Ceased being a customer (set on churn) |
| `renewalDate` | `date` | Next renewal, derived from licenses |
| `renewalDaysFromNow` | `number` | Days until renewal, calculated |
| `autoRenews` | `boolean` | Whether the upcoming renewal auto-renews |
| `lastRenewal` | `date` | Most recent renewal date |
| `products` | `string[]` | Products held, derived from licenses |
| `tags` | `string[]` | Free-form tags |
| `lastActive` | `date` | Last product activity (from usage tracking) |
| `lastTouch` | `date` | Last logged touch (any type) |
| `lastTouchType` | `string` | Type of that last touch |
| `lastTouchByType` | `object` | Map of touch type → last date |
| `custom` | `object` | Tenant-defined custom fields |
| `createdAt`, `updatedAt` | `date` | System timestamps |

Companies can be arranged in parent/child hierarchies (group ↔ subsidiaries); revenue
roll-ups (`mrrTotal`) aggregate over children.

## End User (`/endusers`)

A person at one of your customers — product user, business contact, or both. Can be
created explicitly, or auto-created from tracked usage events and from
conversations/emails whose domain matches a Company's `domains`.

| Field | Type | Description |
|---|---|---|
| `_id` | `ObjectId` | Planhat id |
| `companyId` | `ObjectId → Company` | **Required** (unless resolvable by email domain) |
| `companyName` | `string` | Read-only denormalised company name |
| `name` | `string` | Full name (or set `firstName`/`lastName`) |
| `firstName`, `lastName` | `string` | Name parts |
| `email` | `string` | Primary email; used for matching activity |
| `otherEmails` | `string[]` | Additional email addresses |
| `position` | `string` | Job title / role |
| `phone` | `string` | Phone number |
| `featured` | `boolean` | Marked as a key contact |
| `tags` | `string[]` | Free-form tags |
| `externalId` | `string` | Your id (used as the user id in usage tracking) |
| `sourceId` | `string` | Id in an integrated system |
| `npsUnsubscribed` | `boolean` | Opted out of NPS surveys |
| `lastActive` | `date` | Last tracked product activity |
| `lastTouch` | `date` | Last logged touch |
| `beats` / `beatTrend` | `object` / `number` | Activity level and trend, calculated from usage |
| `experience` | `number` | Individual experience score, calculated |
| `relatedEndUsers` | `ObjectId[]` | Linked end users |
| `custom` | `object` | Custom fields |
| `createdAt`, `updatedAt` | `date` | System timestamps |

## License (`/licenses`)

A customer's subscription — the base for MRR/ARR and most revenue reporting.

| Field | Type | Description |
|---|---|---|
| `_id` | `ObjectId` | Planhat id |
| `companyId` | `ObjectId → Company` | **Required.** Exactly one owning company |
| `externalId`, `sourceId` | `string` | External ids |
| `product` | `string` | Product name; must match the tenant's product list |
| `currency` | `string` | ISO 4217 code, e.g. `"USD"`, `"GBP"` |
| `mrr` | `number` | Monthly recurring value of this license |
| `value` | `number` | Total contract value (alternative to `mrr` for fixed-term licenses) |
| `fromDate` | `date` | **Required.** Start of the (current) term |
| `toDate` | `date` | End of term; open-ended ("until further notice") licenses omit it |
| `fixedPeriod` | `boolean` | Fixed-term contract vs ongoing subscription |
| `renewalPeriod` | `number` | Term length in months (fixed-term) |
| `autoRenews` | `boolean` | Renews automatically at `toDate` |
| `noticePeriod` | `number` | Notice required before renewal, in days/months per tenant config |
| `noticeDate` | `date` | Calculated last day to give notice |
| `renewalStatus` | `string` enum | `ongoing`, `renewed`, `lost` |
| `custom` | `object` | Custom fields |
| `createdAt`, `updatedAt` | `date` | System timestamps |

## Metrics & usage data (time-series)

Product usage is **append-only time-series data**, not CRUD models, sent to
`https://analytics.planhat.com`:

- **User activity (tracking events)** — one JSON event per user action:

  | Field | Type | Description |
  |---|---|---|
  | `email` or `externalId` | `string` | Identifies the end user (auto-creates unknown users) |
  | `companyExternalId` | `string` | Identifies the company |
  | `action` | `string` | Event name, e.g. `"Logged in"`, `"Created report"` |
  | `date` | `date` | Optional; defaults to now |
  | `count` | `number` | Optional weight; defaults to 1 |
  | `info` | `object` | Optional arbitrary event metadata |

- **Dimension data (custom metrics)** — numeric metric points per company (or asset):

  | Field | Type | Description |
  |---|---|---|
  | `dimensionId` | `string` | Metric name/id, e.g. `"activeUsers"` |
  | `value` | `number` | Metric value |
  | `externalId` / `companyExternalId` | `string` | Company (or model instance) the point belongs to |
  | `date` | `date` | Point date |

Aggregates from this data feed calculated company/end-user fields (`lastActive`,
`beats`, health metrics) and Planhat's dashboards.

## Custom fields

Custom fields extend any model. They are defined via the **Custom Field** model
(`/customfields`) and their values live under the parent record's `custom` object.

Custom Field definition:

| Field | Type | Description |
|---|---|---|
| `_id` | `ObjectId` | Planhat id |
| `parent` | `string` | Model the field belongs to, e.g. `company`, `enduser`, `license` |
| `name` | `string` | Field name (the key used inside `custom`) |
| `type` | `string` enum | Data type — see below |
| `listValues` | `string[]` | Allowed options, for list types |
| `isHidden` | `boolean` | Hidden from UI |
| `isFeatured` | `boolean` | Pinned/prominent in UI |

Available custom field types:

| Type | Stored as | Notes |
|---|---|---|
| Text | `string` | Free text |
| Number | `number` | Integer or decimal |
| Date | `date` | Timestamp |
| Day | `string`/`date` | Day-granularity date |
| Checkbox | `boolean` | True/false |
| List | `string` | Single pick from `listValues` |
| Multi-picklist | `string[]` | Multiple picks from `listValues` |
| Rating | `number` | 1–5 style rating |
| Team member | `ObjectId → User` | Reference to a Planhat user |
| URL | `string` | Link |
| Formula | calculated | Derived from other fields, read-only |

## API behaviour summary

- **Auth**: `Authorization: Bearer {api_token}` (tokens are per-tenant, created in
  Planhat settings).
- **Endpoints**: standard REST — `GET /model`, `GET /model/{id}`, `POST /model`,
  `PUT /model/{id}`, `DELETE /model/{id}`; bulk upsert via `PUT /model` with an array.
- **Pagination**: `limit` + `offset` query parameters (max page sizes vary by model,
  2,000–10,000).
- **Field selection**: `select` query parameter to restrict returned fields.
- **Ids in routes**: `{_id}`, `extid-{externalId}`, or `srcid-{sourceId}`.
